### Enable GitHub Pages (3 steps)

1. **Go to Repository Settings**
   - https://github.com/manoj367/Test-Funnel-Portfolio/settings

2. **Navigate to Pages**
   - Scroll to "Pages" in left sidebar

3. **Configure**
   - Source: Deploy from a branch
   - Branch: master
   - Folder: / (root)
   - Click Save
